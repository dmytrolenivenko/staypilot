What the features contribute

How much of the estimate above each feature accounts for. These compound rather than add up, so they will not sum to the total. A sea view is counted at this property's own distance from the beach, where it is worth far more near the water than inland.

The counted features — bathrooms, balconies, floor, energy grade, distance to the beach — are measured against the typical property in this market, not against zero, so “Measured against” is what the amount is a premium (or a discount) over. An ordinary property gets no row for them at all. Greyed rows are features whose confidence range crosses zero: the amount is still part of the estimate, the data just cannot confirm the feature is worth anything.
