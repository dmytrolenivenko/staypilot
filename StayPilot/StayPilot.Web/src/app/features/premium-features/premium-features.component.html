Feature Impact

What each feature is worth, measured by the valuation model while holding size, rooms, condition, beach distance and location still. This is correlation across current asking prices, not causation. Recalculate to refresh from the latest data.

Where a feature is worth wildly different amounts depending on the property — a sea view on the beachfront against one that means a sliver on the horizon — the row also shows what it reaches, and the conditions that figure holds under. Same model, different question: the headline stays the market-wide average.

Every number has a confidence range. Where that range crosses zero the data cannot tell whether the feature affects price at all — those rows say no measurable effect rather than showing a percentage, and sort to the bottom. Features whose ranges overlap cannot be ranked against each other. “Listings with it” is how many of the fitted listings actually carry the feature — the evidence behind that row, and why the rarer ones have wider ranges.
